# پنل مدرسه — مدیریت کلاس + پنل ادمین

ادغام دو پروژه در یک سایت ایستا (بدون نیاز به build):

- **پنل ادمین** (`admin-v2`): قالب RTL با تم جدید «Aurora» (بنفش/فیروزه‌ای، حالت تاریک و روشن)
- **برنامهٔ مدیریت کلاس** (`class-main`): حضور و غیاب، نمرات، کارنامه، پیامک والدین، حساب دانش‌آموزان و …

برنامهٔ کلاس داخل پنل جا گرفته است: ۱۷ بخش آن در منوی کناری «مدیریت کلاس» هست و بدون بارگذاری مجدد صفحه عوض می‌شود. داشبورد پنل آمار واقعی (کلاس‌ها، دانش‌آموزان، نمرات، حضور و غیاب) را از داده‌های همان برنامه می‌خواند. دکمهٔ ☁️ بالای صفحه منوی حساب ابری برنامه را باز می‌کند.

## ساختار
```
index.html            داشبورد مدرسه
pages/school/         صفحهٔ میزبان برنامهٔ مدیریت کلاس
class/                برنامهٔ مدیریت کلاس (index.html + آیکون‌ها + manifest)
pages/accounts/       فهرست حساب‌های دانش‌آموزان (چه کسانی حساب دارند)
assets/               استایل، فونت وزیرمتن، فونت‌آیکون، جاوااسکریپت
```

## انتشار روی GitHub Pages
1. یک مخزن جدید بسازید و همهٔ فایل‌ها را (با `.nojekyll` و پوشهٔ `.github`) در شاخهٔ `main` آپلود کنید.
2. در `Settings ← Pages` گزینهٔ **Source** را روی **GitHub Actions** بگذارید (یا `Deploy from a branch` ← `main` ← `/ (root)`).
3. پس از یکی دو دقیقه سایت در `https://USERNAME.github.io/REPO/` بالا می‌آید.

## اجرای محلی
```
python3 -m http.server 8000
```
سپس `http://localhost:8000` را باز کنید. (بهتر است فایل را مستقیم با `file://` باز نکنید.)

## نکته‌ها
- داده‌های برنامه در مرورگر ذخیره می‌شود؛ پنل و برنامه روی یک دامنه‌اند، پس داشبورد همان داده‌ها را می‌بیند.
- ورود دانش‌آموزان و همگام‌سازی ابری نیاز به اجرای یک‌بارهٔ `cm-portal.sql` در Supabase دارد (جزئیات در `class/README.md`).
- کلید `sb_publishable_…` داخل `class/index.html` کلید عمومی است؛ امنیت داده با سیاست‌های RLS در Supabase تامین می‌شود.

## چند مدرسه
از لیست بالای صفحه یا کارت «مدرسه‌ها» در داشبورد می‌توانید مدرسه اضافه کنید یا جابه‌جا شوید. هر مدرسه داده‌های جدا (کلاس، دانش‌آموز، حضور، نمره، حساب‌ها) دارد و با جابه‌جایی چیزی پاک نمی‌شود. مدرسهٔ تازه از صفر شروع می‌شود. توجه: همگام‌سازی ابری برنامه یک حساب ابری را برای مدرسهٔ فعال استفاده می‌کند؛ برای هر مدرسه حساب ابری جدا وارد کنید.
